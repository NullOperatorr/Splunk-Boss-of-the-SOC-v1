## Project Overview

This repository documents my investigation and analysis of BOTS v1 Scenarios 1 and 2, with a focus on developing practical skills in Splunk Search Processing Language (SPL), security log analysis, investigation methodology, and threat hunting.

Boss of the SOC (BOTS) is a security investigation challenge created by Splunk. It provides realistic security-related data and investigation questions that require analysts to search, correlate, and analyze events using Splunk.

For this project, I am focusing on BOTS v1, specifically:

**Scenario-1** ()  
**Scenario 2** ()  

Rather than documenting only the final answers, this project focuses on the investigation process behind each finding.

The objective is to demonstrate how Splunk can be used to:

- Search and analyze security events.
- Develop and refine SPL queries.
- Correlate events and indicators.
- Investigate suspicious activity.
- Extract meaningful security findings from large datasets.

## Lessons Learned

The main objectives of this project are to strengthen practical Splunk skills through hands-on investigation.
